# 多门店批量对比 & 利润目标反推 设计文档

> 日期：2026-07-01
> 状态：已确认

---

## 1. 背景

当前应用围绕单门店测算，用户需要手动逐个导入门店数据并保存后才能在方案对比中查看。对于管理多个门店的战区经理/财务人员，这个流程非常低效。同时，用户希望从目标利润出发反推所需条件，而非只能正向输入数据看结果。

---

## 2. 功能一：多门店批量对比

### 2.1 流程

1. 用户在简洁模式 Header 或专业模式侧边栏点击「批量导入」
2. 系统弹出文件夹选择对话框
3. 扫描文件夹内所有 `.xlsx` 文件，逐个解析
4. 每个文件自动检测单/多品类（复用 `excel:import` 的 `auto` 模式）
5. 全部解析完成后展示对比视图

### 2.2 模板

**不新增模板**。使用现有的单品类和多品类模板，每家门店一个文件，全部放入同一文件夹即可。

### 2.3 对比视图

#### 卡片排名视图（默认）

- 每家门店一张摘要卡片：门店名、利润、保本点、安全边际率
- 顶部统计栏：共 N 家门店，合计利润 ¥X，平均安全边际率 Y%
- 支持按利润/保本点/安全边际排序
- 颜色标记：盈利绿色、亏损红色、临界黄色

#### 表格明细视图（切换）

- 门店 × 全面指标矩阵表
- 复用 ScenarioCompare 的指标选择机制（产品结构 / 变动费用明细 / 固定费用明细均可选）
- 最大值行高亮，负值红色
- 核算模式自动适配（倒扣制/顺加制）

### 2.4 技术实现

**主进程新增 IPC 通道**：
```
batch:import → 选文件夹 → 扫描 .xlsx → 逐个调用 parseSingleExcel/parseMultiExcel → 返回数组
```

**渲染进程新增组件**：
- `BatchCompare.tsx` — 批量对比容器（卡片视图 + 表格视图切换）
- `StoreCard.tsx` — 单门店摘要卡片
- `BatchTable.tsx` — 门店 × 指标矩阵表

**入口**：
- 简洁模式：Header 工具栏增加「批量导入」按钮
- 专业模式：侧边栏导航或测算输入页工具栏增加入口

## 3. 功能二：利润目标反推

### 3.1 流程

1. 用户在测算页面输入目标利润（元/月）
2. 选择反推方式（销售额 / 毛利率 / 压降费用）
3. 系统在当前数据结构基础上计算目标值
4. 结果直接展示在页面上（不弹窗），与当前值对照

### 3.2 反推公式

**A. 提高销售额**
```
所需销售额 = (目标利润 + 固定费用 - 补贴) ÷ 加权CMR
各系列需增加销售额 = 所需销售额 - 当前销售额（按当前结构比例分配）
```

**B. 提高毛利率**
```
所需毛利率 = 变动费率 + (目标利润 + 固定费用 - 补贴) ÷ 当前销售额
```

**C. 压降费用**
```
目标总费用 = 当前销售额 × 当前毛利率 - 目标利润
```

### 3.3 展示方式

在单品类视图左侧输入区底部新增「目标反推」折叠面板：
- 输入框：目标利润
- 三个结果行：所需销售额 / 所需毛利率 / 需压降费用
- 每行显示：目标值 vs 当前值，差距（+/-）

### 3.4 技术实现

**计算引擎扩展**（`shared/calc/`）：
- 新增 `goalSeek.ts`，包含三个反推函数
- 纯函数，不依赖 React

**渲染**：
- 简洁模式：`SimpleApp.tsx` SingleCategoryView 底部新增面板
- 专业模式：`CalculatorPage.tsx` 输入区新增面板

## 4. 验收标准

### 批量对比
- [ ] 选择文件夹后自动扫描 Excel，显示解析进度
- [ ] 解析结果包含每家门店的名称和关键 KPI
- [ ] 卡片视图支持排序（利润/保本点/安全边际）
- [ ] 可切换到表格明细视图，勾选指标列
- [ ] 导入模板无需改动，与现有模板完全兼容
- [ ] 两个模式（简洁/专业）均可使用

### 利润目标反推
- [ ] 输入目标利润后三个反推结果实时计算
- [ ] 结果与当前值对照展示
- [ ] 加权 CMR ≤ 0 时提示"当前条件下无法盈利"
- [ ] 数据变化时反推结果自动更新

---

## 5. 技术约束

- 批量导入复用现有 `excel-parser.ts`，不修改解析逻辑
- 反推函数独立于计算引擎，不修改 `calculator.ts`
- 两个功能互不依赖，可独立开发和测试
